# Customer Service Chatbot 💬🤖

A rule-based and keyword-matching customer service chatbot built in Python to handle automated user inquiries.

## 🚀 Features
* **Intent Recognition:** Uses regular expressions (`re`) to parse user inputs and identify specific intents such as greetings, order tracking, refund policies, and working hours.
* **Dynamic Responses:** Returns randomized, natural-sounding replies from a predefined response bank to enhance the simulated user experience.
* **Lightweight & Fast:** Built purely using Python standard libraries without requiring heavy external dependencies.

## 🛠️ Tech Stack
* **Language:** Python
* **Core Modules:** `re` (Regular Expressions), `random`

## 💻 How to Run
1. Clone the repository or download the script file.
2. Ensure you have Python installed on your system.
3. Run the script from your terminal:
   ```bash
   python chatbot.py
